# Global Superstore Power BI Dashboard

## Project Overview
This project focuses on analyzing Global Superstore sales data using Microsoft Power BI. An interactive dashboard was developed to transform raw data into meaningful business insights and support data-driven decision-making.

## Objectives
- Analyze overall sales and profit performance.
- Identify top-performing regions and markets.
- Understand product category and segment performance.
- Analyze geographical sales distribution.
- Identify business trends through interactive visualizations.

## Tools & Technologies
- **Microsoft Power BI** – Dashboard development and data visualization.
- **Microsoft Excel** – Dataset management and preparation.

## Dataset
The Global Superstore dataset contains transactional information, including:
- Order ID and Order Date
- Customer and Product Details
- Sales and Profit
- Quantity and Discount
- Market, Region, State and City

## Dashboard Features
- Sales Performance Analysis
- Profit Analysis
- Regional Sales Distribution
- Market-wise Analysis
- Category and Segment Analysis
- Interactive Slicers and Filters

## Project Files
- `Global_Superstore_Sales_Analysis.pbix` – Power BI dashboard file.
- `Global_Superstore_Dataset.xlsx` – Original dataset.

## Key Insights
The dashboard helps explore sales trends, profitability, regional performance, and product-wise business performance through interactive reports.

## Conclusion
This project demonstrates the use of Power BI for data analysis and visualization. It provides an effective way to explore business performance and gain meaningful insights from transactional data.
